# Proyecto EDA

Este repositorio contiene un análisis exploratorio de datos (EDA) basado en una campaña de marketing bancario. Incluye carga, limpieza, análisis estadístico y visualizaciones.

## Contenido

- Carga de datos desde CSV y Excel
- Limpieza y unión de datasets
- Análisis estadístico y de valores nulos
- Visualizaciones con Seaborn y Matplotlib
- Informe final de conclusiones
